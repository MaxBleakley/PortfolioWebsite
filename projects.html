Below are just a few of the projects and technologies I make use of in my free time!

Proxmox

I currently run a powerful homelab which uses proxmox as it’s hypervisor. My proxmox is clustered in a 3 cluster node. It runs a total of 42 CPU cores, 150GB of ram and 7TB of storage. Within these nodes i have 4 LXC Containers, and 3 VM’s

Docker

As mentioned above, my homelab makes use of LXC containers and Linux VM’s. All of which have Docker containers deployed within them. The most vital containers I make use of include my Unifi controller, responsible for managing my Unifi AP and Switch. Pihole, which acts as a network wide adblocker, uptime Kuma which is used for monitoring the uptime of different services and finally, paperless, which I use to manage my documents

Linux

Linux is an OS I have become proficient in recently due to my home lab running Linux based proxmox, Ubuntu server based VM’s and containers as well as switching my daily driver laptop too Arch Linux among other distributions.

OPNsense Router

Within my homelab environment, I have deployed an OPNSense router within my home network, This is the current router I use, and it provides valuable information and experience on the intricacies of deploying a router making use of open source software.

Ubiquiti

Ubiquiti is a company I have become increasingly familiar with. After moving house I began finding dead zones for wi-fi. With this came the realization that my ISP provided hub was insufficient. After careful consideration I purchased 2 Ubiquiti Access Point’s as well as a 16 pro max POE network switch. I am looking to upgrade to a Dream Machine Pro in the near future.
